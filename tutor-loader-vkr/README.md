# Расширение EduRAG Loader для ВКР

Утверждённая тема: **Разработка программного сервиса интеграции и гибридного поиска научно-технической документации**.

Архитектура: существующий **PostgreSQL + pgvector**, дополнительное хранилище оригиналов **MinIO**. MongoDB не используется.

Пакет содержит проектную документацию и архитектурный прототип, а не реализованный сервис. Основа — актуальная документация [EduTutor](https://github.com/BosenkoTM/llm-data-analytics-tutor). Автор исходного проекта: Босенко Т. М. Срез main зафиксирован в источниках.

## Место конференционного исследования в ВКР

Конференционный доклад **«Организация информационного обеспечения RAG-систем»** (Батраков С. А.; научный руководитель Босенко Т. М.) представляет **научно-архитектурный этап** ВКР «Разработка программного сервиса интеграции и гибридного поиска научно-технической документации». Доклад рассматривает согласованное хранение поисковых представлений и исходных PDF/DOCX, привязку фрагментов к точной версии документа и предоставление доступных первоисточников. 

Объём ВКР шире доклада: программная реализация MinIO и API документов, управление версиями и доступом, три режима поиска (FTS, векторный, гибридный с RRF), пользовательский каталог и экспериментальные испытания. Материалы доклада используются как обоснование проектных решений, а не как подтверждение готовности программных функций или результатов эксперимента.

Связь с разделами ВКР: анализ проблемы и источников — глава 1; архитектура оригиналов, фрагментов и версий — глава 2; разработка интеграционного сервиса и гибридного поиска — глава 3; проверка согласованности, релевантности и производительности — глава 4 (планируемая структура пояснительной записки).

## Схемы

В `diagrams/` находятся четыре файла `.mmd`; в Markdown те же схемы встроены в блоки `mermaid`. В `assets/` находятся изображения для печати. Цвета: синий — существующие сервисы; зелёный — данные; бирюзовый — участники; фиолетовый — ИИ; оранжевый — доработки студента.

## Размещение в GitHub

Скопируйте этот каталог в `docs/vkr-loader-minio/` репозитория либо используйте как отдельный каталог документации ВКР. Сохраняйте относительные пути. GitHub отображает Mermaid в Markdown. Не заменяйте текущие архитектурные материалы проектными схемами без отдельного решения о внедрении.

В пакете нет секретов, рабочих конфигураций, студенческих решений и утверждений о готовности новых функций. Архитектура не требует переработки LangGraph, MCP, Moodle и локальной LLM. Интеграция нового поиска с ответами Tutor является отдельным этапом.
