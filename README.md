# EduTutor — интеллектуальная поддержка обучения анализу данных

**Грантовый проект «LLM-ассистент для интеллектуальной поддержки обучения анализу данных в магистратуре»**  
**Московский городской педагогический университет · Институт цифрового образования**  
Программа поддержки: **Грантовый конкурс для преподавателей Благотворительного фонда Владимира Потанина (2026)**.

**EduTutor** — образовательная система, которая помогает магистрантам осваивать анализ данных на практических заданиях, а преподавателю — сопровождать выполнение и предварительную проверку работ. Интеллектуальная помощь строится на материалах конкретной дисциплины. **Окончательную оценку выставляет преподаватель.**

> Репозиторий представляет **сам продукт: образовательный сценарий, функции компонентов и архитектуру**. Здесь нет исходного кода, внутренних конфигураций, студенческих работ и решений преподавателя.

Студент получает помощь **во время** работы, а не готовое решение. Тьютор поясняет постановку задачи, способы сбора и обработки данных, ошибки Python-кода и требования к результату, используя доступные материалы преподавателя.

Преподаватель составляет задания, публикует учебные материалы в базе знаний и может использовать **Агента-Ассистента** для предварительного разбора работ. Решение об оценке остаётся за преподавателем.

| Участник | Что предоставляет EduTutor |
|---|---|
| **Магистрант** | Пояснения по заданиям и терминам, помощь с кодом и интерпретацией результатов, ориентиры для самостоятельной работы |
| **Преподаватель** | Организацию базы учебных знаний, предварительные замечания к работам, поддержку проверки по заданным критериям |
| **Дисциплина** | Связь пояснений с учебной темой, заданием и проверенными материалами |

**Подробно:** [маршрут студента](education/01_student_path.md) · [работа преподавателя](education/02_teacher_path.md) · [дисциплины и учебные активности](education/03_courses.md).

## 2. Дисциплины и практическая подготовка

Проект ориентирован на магистратуру **38.04.05 «Бизнес-информатика»**, профиль **«Бизнес-аналитика и большие данные»**, и первоначально охватывает две дисциплины:

| Дисциплина | Направленность обучения |
|---|---|
| **Python для анализа данных** | Работа с данными средствами Python: подготовка, анализ и представление результатов |
| **Программные средства сбора, консолидации и аналитики данных** | Получение данных из API и веб-источников, очистка, консолидация, аналитика и управленческие выводы |

Практические и лабораторные работы связаны с **конкретными заданиями Moodle**. Учебные материалы могут включать текст условия, индивидуальные варианты, Jupyter Notebook, критерии оценивания и требования к результату. Связь с конкретным вариантом студента является отдельным направлением повышения точности контекста.

## 5. Возможности и развитие

**Реализованная основа продукта:** сервис загрузки и публикации учебных материалов; структурирование дисциплин, тем и занятий; векторное хранилище знаний; агентная архитектура EduTutor; переход из Moodle к помощнику. В EduRAG Loader реализовано структурно-семантическое переранжирование `hybrid_v1` для проверки качества поиска.

**Следующий этап интеграции:** единый механизм поиска для Loader и EduTutor, точное сопоставление задания Moodle и учебной активности, учёт индивидуального варианта и отображение источников непосредственно в ответе. Эти функции не следует считать полностью внедрёнными во все компоненты.
