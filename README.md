# EduTutor — интеллектуальная поддержка обучения анализу данных

**Грантовый проект «LLM-ассистент для интеллектуальной поддержки обучения анализу данных в магистратуре»**  
**Московский городской педагогический университет · Институт цифрового образования**  
**Благотворительный фонд Владимира Потанина · грант № ГСГК-064/26 (2026)**

**EduTutor** — образовательная LLM-система для поддержки магистрантов при выполнении заданий по анализу данных. Тьютор помогает работать с условиями, кодом и учебными материалами; преподаватель определяет критерии и принимает итоговые решения об оценивании. Исследовательский контур проекта посвящён **верифицируемой многоагентной оркестрации**.

> **Область публикации.** Этот репозиторий содержит публичное описание образовательного продукта, архитектуры, компонентов и исследовательских направлений. Исходный код рабочего прототипа, локальные конфигурации, пароли, учебные данные и персональные сведения здесь **не публикуются**. Сведения о проверках ниже относятся к зафиксированному испытанию **25 октября 2026 года**, а не к текущему доступу к сервисам.

## 1. Образовательный маршрут

```mermaid
flowchart LR
    S["Магистрант"] --> M["Moodle 5: задание"]
    M --> W["Workspace: помощник"]
    W --> T["Tutor: объяснение и RAG"]
    T --> P["Самостоятельное выполнение"]
    P --> M
    M --> H["Преподаватель: проверка"]
    H -. "обратная связь" .-> P
```

Тьютор поясняет постановку задачи, подходы к обработке данных, ошибки Python/SQL и смысл результатов. Он не должен раскрывать закрытые эталонные решения или заменять самостоятельную работу. Преподаватель управляет учебным содержанием и итоговой оценкой.

## 3. Архитектура: три независимых контура

```mermaid
flowchart TB
    subgraph STUDENT["STUDENT · подтверждённое ядро"]
      M["Moodle 5"] --> W["Workspace :3010"] --> T["Tutor :8111"]
      T --> Q["Ollama :11434"]
      T --> DB[("PostgreSQL / pgvector")]
    end
    subgraph MAS["MAS · исследовательский контур"]
      O["Orchestrator :8100"] --> A1["a1 · Tutor in-process"]
      O --> A2["a2 · проверка кода"]
      O --> A3["a3 · планирование"]
      A2 --> MC["MCP · stdio"]
    end
    subgraph TEACHER["TEACHER · интерфейс запланирован"]
      U["/teacher · НЕ реализован"] -.-> A["Assistant :8102 · draft/HITL backend"]
    end
    L["EduRAGLoader :6800"] --> DB
```

**Важно:** STUDENT, MAS и TEACHER — разные пути. Успешный `/tutor/complete` не доказывает выполнение Orchestrator; агент `a1` использует Tutor *in-process*, а не вызов HTTP :8111. Для MCP используется **stdio**, HTTP-сервис :8000 в проверенном профиле не нужен. Teacher UI, серверный RBAC и полный HITL E2E ещё не внедрены.

## 4. Сервисы прототипа

| Компонент | Интерфейс | Роль |
|---|---|---|
| **Workspace** | :3010 | Студенческий Next.js/CopilotKit интерфейс |
| **Tutor** | :8111, `/tutor/complete` | LLM-ответы с контекстом RAG |
| **Orchestrator** | :8100 | Маршрутизация, граф, делегирование агентам |
| **Assistant** | :8102 | Предварительные замечания, HITL backend; без готового teacher UI |
| **EduRAGLoader** | :6800 | Каталог, подготовка материалов; в испытании — безопасный read-only просмотр |
| **MCP** | stdio | Инструменты валидации и работы с ресурсами; не отдельный HTTP :8000 |
| **Ollama** | :11434 | Локальная модель семейства Qwen |
| **PostgreSQL/pgvector** | удалённый :5432 | Хранение и семантический поиск учебных фрагментов |
| **Moodle 5** | внешний LMS | Курсы, задания, подписанный запуск помощника |

Порты приведены как сведения об **испытанной конфигурации**, а не как публичные сетевые адреса или инструкция развертывания.

## 5. Подтверждённая работоспособность и ограничения

На срезе испытаний **25.10.2026**:

- **PASS:** Workspace/Tutor, ответ локальной модели не в mock-режиме, поиск RAG по наполненному курсу; EduRAGLoader в режиме read-only GET; health основных сервисов.
- **PASS в отдельном тестовом процессе:** сценарии `a1`, MCP `validate_code` у `a2`, черновик Assistant.
- **NOT_VERIFIED:** вызов MCP непосредственно через действующие AG-UI процессы Orchestrator/Assistant; запуск Moodle с реальной HMAC-сессией.
- **NOT_IMPLEMENTED / DEFERRED:** `/teacher` и полный преподавательский HITL E2E; РПД отложены по решению проекта.
- **NOT_STARTED:** новые научные испытания K1–K4 после консолидации.

Не смешивать проверки companion с пользовательскими E2E и историческую научную апробацию (5220 запросов) с новыми тестами. [Реестр статусов](architecture/06_verification.md).
