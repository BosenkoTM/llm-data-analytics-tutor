# 3. Использованный инструментарий

## Стек по слоям (обобщённо)

| Слой | Технологии |
|---|---|
| Клиент (UI) | HTML5, Bootstrap, серверные шаблоны Flask |
| Сервер приложений | Python 3.x, Flask, загрузка файлов multipart |
| Обработка текста | Python: разбор метаданных документа, семантическое разбиение на фрагменты |
| ML / эмбеддинги | SentenceTransformers, локальная многоязычная модель семейства e5, PyTorch |
| СУБД | PostgreSQL с расширением pgvector (векторный тип, индекс для cosine-поиска) |
| Доступ к БД | драйвер PostgreSQL для Python, транзакционная запись |

Точные версии пакетов, полный список зависимостей и внутренние пути каталогов **не публикуются**.

## Конфигурация (без секретов)

| Ресурс | Назначение |
|---|---|
| Переменные окружения | Подключение к СУБД и секрет сессии веб-приложения (значения не раскрываются) |
| Локальный кэш модели | Веса эмбеддингов загружаются в контур вуза, без отправки текстов во внешний embedding-API |
| Шаблоны материалов | Комплекты учебных `.md` по дисциплинам (содержимое УМК не публикуется) |
| Потребители индекса | EduTutor (агенты), MCP-ресурсы материалов — **чтение** того же хранилища |

## Языки

- **Python** — серверная логика, обработка текста, эмбеддинги, доступ к БД.
- **SQL** — хранение фрагментов и векторов, контрольные агрегаты по курсам.
- **HTML/CSS** — форма загрузки и предпросмотр в браузере.
