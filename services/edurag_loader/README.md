# EduRAG Loader — подготовка образовательной базы знаний

[← Главная](../../README.md) · [Маршрут преподавателя](../../education/02_teacher_path.md)

**EduRAG Loader** — сервис преподавателя для упорядочивания учебных материалов и их публикации в базе знаний EduTutor.

## Возможности

| Возможность | Что получает преподаватель |
|---|---|
| Каталог дисциплин | Связь уровня образования, направления, профиля, дисциплины и `rag_key` |
| Темы и занятия | Учёт лекций, практических, лабораторных и других занятий |
| Материалы | Ввод текста задания, прикрепление файлов и Jupyter Notebook |
| Предпросмотр | Проверка извлечённого текста и будущих фрагментов до публикации |
| Публикация | Запись фрагментов и векторов в PostgreSQL/pgvector |
| Проверка знаний | Поиск фрагментов по вопросам с фильтрами дисциплины и занятия |

## Последовательность работы

**Выбрать дисциплину → создать занятие → прикрепить материалы → проверить предпросмотр → опубликовать → проверить поиск.**

В Loader реализовано структурно-семантическое переранжирование `hybrid_v1` для диагностического поиска. Его использование в пользовательских ответах EduTutor ещё является отдельной задачей интеграции.

Преподавательские решения, персональные данные студентов и рабочие конфигурации не входят в публичные материалы.
