# EduRAG Loader — проектная документация (публичный контур)

Веб-сервис индексации учебных материалов в векторное хранилище для последующего RAG в
системе **EduTutor** (грант № ГК26-000535). Преподаватель загружает структурированные
учебные документы; сервис выполняет разбиение на фрагменты, строит эмбеддинги и сохраняет
их в аналитическое хранилище **только после явного подтверждения** предпросмотра.

| | |
|---|---|
| Роль в контуре | Сервис **наполнения RAG** (ingest), не чат-интерфейс тьютора |
| Грант | № ГК26-000535, Фонд В. Потанина |
| Университет | МГПУ · ИЦО · 38.04.05 «Бизнес-информатика» |
| Потребители индекса | EduTutor (Тьютор / Ассистент / MCP) |

> **Публичная документация.** Приведены архитектурные и академические описания без полного
> исходного кода, точных параметров пайплайна, DDL/паролей и инструкций, достаточных для
> побайтового воспроизведения закрытой реализации. Рабочий код остаётся в закрытом контуре гранта.

## Кратко о стеке

**Фронт:** серверные шаблоны + Bootstrap. **Бэк:** Python, Flask. **БД:** PostgreSQL + pgvector.  
**ML:** локальная многоязычная модель эмбеддингов (семейство e5-class).
