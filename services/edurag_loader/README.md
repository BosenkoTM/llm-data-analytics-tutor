# EduRAGLoader — каталог и подготовка базы знаний

[← Главная](../../README.md) · [RAG](../../architecture/03_rag.md)

**EduRAGLoader** — сервис подготовки и управления учебными материалами дисциплин: каталог → тема/занятие → извлечение текстов → фрагментация → эмбеддинги → PostgreSQL/pgvector. Работа с материалами и публикация в базу знаний отличаются от read-only просмотра уже существующего корпуса.

## Проверенное состояние

На испытании **25.10.2026** сервис Flask был запущен с защитным флагом `EDURAG_READONLY_BOOT=1` и read-only транзакциями PostgreSQL. Подтверждены GET-просмотр каталога и отклонение изменяющих HTTP-маршрутов; новых материалов не загружали и индексацию не выполняли.

- **PASS:** запуск, health, GET и блокировка write routes в read-only профиле.
- **Ограничение:** отдельная PostgreSQL-роль SELECT-only не была создана; защита полагалась на режим приложения и сеанса.
- **Не утверждается:** успешная новая публикация учебного корпуса в этом испытании.

`hybrid_v1` относится к диагностическому поиску/переранжированию Loader. Его наличие **не означает**, что этот механизм уже используется во всех ответах Tutor.

В подтверждённом срезе база RAG содержит **712 фрагментов** по курсу сбора и консолидации данных и **0** по курсу Python для анализа данных. Значения могут меняться после нового наполнения.
