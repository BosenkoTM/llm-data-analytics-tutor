# 8. Перспективы проекта (масштабирование)

## Применение вне текущего пилота

| Контекст | Как использовать Loader |
|---|---|
| Другие дисциплины ИЦО / МГПУ | Новый идентификатор курса + комплект шаблонов, без смены агентов |
| Корпоративное обучение | Индексация внутренних регламентов → корпоративный RAG-ассистент |
| Научно-методическая работа | Версионирование УМК + управляемый ingest в DWH |
| Бизнес-аналитика | Кейс ETL/MLOps: документ → фрагмент → embedding |

## Ресурсы для внедрения

| Тип | Оценка для пилота кафедры |
|---|---|
| Серверные | Сервер приложений с запасом RAM под локальные эмбеддинги; PostgreSQL с pgvector; место под модели и БД |
| Кадровые | Преподаватель-владелец контента; при тираже — доля ставки инженера сопровождения |
| Финансовые | On-prem (без обязательной платы за внешний embedding-API при локальной модели) |
| Организационные | Регламент: кто подтверждает предпросмотр; резервное копирование хранилища знаний |

## Масштабирование техническое

1. Очередь фоновых задач для тяжёлых пакетов эмбеддингов.
2. Объектное хранилище исходников + аудит подтверждений записи.
3. Мультитенантность по факультетам / курсам, политики доступа на уровне СУБД.
4. CI с обязательным E2E-сценарием из [`07_e2e_tests.md`](07_e2e_tests.md).

### Направления доработки

1. **Шифрование канала и данных** — HTTPS для UI; шифрование томов/чувствительных полей;
   запрет отправки учебных текстов во внешние embedding-API.
2. **Ролевая модель (RBAC)** — разделение ролей автора контента, подтверждающего запись и аудитора;
   журнал «кто подтвердил индексацию».
3. **IoT в образовании** — индексация регламентов безопасности IoT для RAG-помощника педагогов;
   ролевая фильтрация выдачи (киоск / кабинет администратора).
4. **Угрозы и контроль** — санитизация загрузок, проверка целостности комплектов шаблонов,
   сегментация сети Loader/БД и IoT-шлюза.

### Учебный эффект для 44.04.01

Сквозной кейс: *безопасный сбор данных и документов → консолидация в DWH → контролируемый
ИИ-доступ*, опирающийся на пайплайн EduRAG Loader и расширяемый требованиями курса по ИБ ОУ.
