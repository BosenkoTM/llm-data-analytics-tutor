# Moodle `local_edututor` — переход к помощи из задания

[← Главная](../../README.md) · [Маршрут студента](../../education/01_student_path.md)

Плагин **`local_edututor`** для Moodle 5 предоставляет доступ к EduTutor из страницы учебного задания `mod_assign`. Он обеспечивает переход между LMS и помощником, а не выполняет оценивание внутри Moodle.

## Текущая роль

- открывает интерфейс EduTutor в контексте курса и задания;
- передаёт подписанный HMAC-контекст запуска;
- сохраняет Moodle основным местом выдачи и сдачи заданий;
- **не записывает оценки в журнал Moodle**.

## Направление развития

Для точной работы с индивидуальными заданиями необходимо согласованно передавать устойчивые идентификаторы курса и задания, связывать их с учебной активностью EduRAG Loader и учитывать номер варианта и актуальность исходного документа.

Пока эти улучшения не прошли сквозную проверку, они обозначаются как планируемые.
