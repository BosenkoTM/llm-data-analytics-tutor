# EduTutor — Агент-Тьютор, Orchestrator и Агент-Ассистент

[← Главная](../../README.md) · [Архитектура агентов](../../architecture/02_agents.md)

EduTutor объединяет самостоятельный студенческий Tutor, исследовательский Orchestrator и backend помощника преподавателя. **Это не один и тот же HTTP-маршрут.**

| Компонент | Назначение | Подтверждение на 25.10.2026 |
|---|---|---|
| **Tutor :8111** | Объяснение задания с учётом учебного RAG; `/tutor/complete` | **PASS**: модель + найденные фрагменты |
| **Orchestrator :8100** | Выбор специализированного агента; модель маршрутов `routing_v3` | **PARTIAL**: routing/companion a1/a2, live AG-UI MCP **NOT_VERIFIED** |
| **Assistant :8102** | Черновой разбор работы по критериям, основа HITL | **PARTIAL**: companion draft PASS, Teacher UI отсутствует |
| **MCP stdio** | Инструменты, например `validate_code` | **PASS companion**; не считать живым AG-UI E2E |

**Для студента:** помощь в понимании условий, ошибок Python/SQL и выводов, без подмены самостоятельного решения. **Для преподавателя:** предварительные замечания, а не автоматическая оценка.

**В развитии:** защищённый `/teacher` и полномочия преподавателя, подтверждение HITL, непрерывная трассируемость, полная интеграция источников. Новые критерии K1–K4 ещё не испытаны.
