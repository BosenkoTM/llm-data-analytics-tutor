# EduTutor — помощник магистранта и преподавателя

[← Главная](../../README.md) · [Образовательный маршрут](../../education/01_student_path.md)

Пользовательский сервис EduTutor объединяет **Агента-Тьютора** для студента и **Агента-Ассистента** для преподавателя. Назначение сервиса — поддерживать работу с учебными материалами, а не заменять самостоятельную работу или итоговую проверку.

## Для студента

EduTutor помогает понять условие, уточнить требования к этапам выполнения, разобрать ошибки Python-кода и интерпретировать результаты работы с данными. Ответ должен учитывать предмет дисциплины и опубликованные преподавателем материалы.

## Для преподавателя

Агент-Ассистент помогает подготовить предварительные замечания к выполненной работе и сопоставить её с критериями. **Итоговая оценка остаётся за преподавателем.**

## Техническая основа

Используются агентная оркестрация LangGraph, инструменты MCP, RAG-контекст из PostgreSQL/pgvector, локальная модель Qwen через Ollama и веб-интерфейс CopilotKit / AG-UI.

**В развитии:** единый поиск с EduRAG Loader, точное сопоставление задания и варианта, отображение источников и версии материалов в интерфейсе. Эти возможности ещё требуют сквозной проверки.
