# Доступ и безопасные границы EduTutor

[← Архитектура](01_overview.md) · [Проверка реализации](06_verification.md)

Публикуемая архитектура отделяет открытые материалы для студентов от закрытых преподавательских эталонов, данных пользователей и служебных ключей.

- **Moodle:** HMAC подтверждает происхождение контекста запуска, но не заменяет серверную проверку полномочий. Полный live HMAC E2E по состоянию 25.10.2026 не подтверждён.
- **Student Tutor:** учебный RAG не должен раскрывать закрытые решения или чужие сведения; фактический E2E всех проверок доступа требует отдельного аудита.
- **Teacher Assistant:** draft/HITL backend не означает работающую систему выставления оценок. UI, server-side RBAC и авторизованное подтверждение преподавателя пока не реализованы.
- **EduRAGLoader:** испытан режим `EDURAG_READONLY_BOOT` с блокировкой изменяющих HTTP-маршрутов и режимом PostgreSQL read-only на уровне сеанса. **Отдельная роль PostgreSQL только с SELECT не применялась**; поэтому гарантии на уровне ролей не заявляются.
- **MCP:** вызовы инструментов должны соответствовать разрешениям конкретного агента, а исполнение пользовательского кода — изолироваться.

Публичный репозиторий не содержит рабочие `.env`, секреты, журналы со студенческими данными, дампы БД, резервные копии конфигураций и закрытый код прототипа. Исторические испытания и проектные диаграммы не являются сертификатом безопасности всей системы.
