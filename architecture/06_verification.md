# Проверенная реализация и ограничения

[← Главная](../README.md) · [Архитектура](01_overview.md)

**Контекст:** результаты внутренних интеграционных проверок прототипа от **25 октября 2026 года**. Они фиксируют подтверждённое на тот момент состояние, но не являются непрерывным мониторингом сервисов или новыми результатами научной апробации.

| Контур / функция | Что проверено | Статус |
|---|---|---|
| Workspace → Tutor → локальная Qwen | HTTP `/tutor/complete`, ответ без mock | **PASS** |
| Tutor → RAG | Выборка 5 фрагментов наполненной дисциплины | **PASS** |
| Orchestrator | Health / `routing_v3` и сценарий a1 в отдельном процессе | **PARTIAL** |
| MCP validate_code | Companion a2 в stdio-профиле | **PASS (companion)** |
| Assistant draft | Черновик предварительного оценивания в отдельном процессе | **PASS (companion)** |
| Live AG-UI → MCP | Прямой вызов через работающие O/A | **NOT_VERIFIED** |
| EduRAGLoader → PostgreSQL | Read-only boot, GET, запрет write routes и сеанс read-only | **PASS (ограниченный режим)** |
| Moodle HMAC → Workspace | Полная реальная пользовательская сессия | **NOT_VERIFIED** |
| Teacher Workspace / RBAC / HITL E2E | Проектируемый UI и защищённое подтверждение | **NOT_IMPLEMENTED** |
| РПД | Наполнение источников | **DEFERRED** |
| Новые научные измерения K1–K4 | Воспроизводимая экспериментальная серия | **NOT_STARTED** |

**Пояснение:** работоспособный health endpoint, правильная переменная окружения и успешный companion-тест — это разные уровни доказательства. Один не заменяет другой.

Научная модель включает автомат M, классификацию τ, переходы δ, каталог Θ и доказательную трассу λ. Историческая исследовательская апробация **5220 запросов** не равна интеграционным тестам 25.10.2026. В публичном репозитории не публикуются внутренние журналы, секреты или стендовые адреса.
