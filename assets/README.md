# Цветные схемы EduTutor в формате Mermaid

Каждая схема в этом каталоге представлена исходным файлом `.mmd` и **встроена как блок `mermaid`** в соответствующие страницы документации. GitHub непосредственно отображает цветные диаграммы в Markdown.

Для изменения цвета используйте определения `classDef` и стили `style` в конце файла. Палитра: тёмно-синий `#142C59`, синий `#2774C7`, бирюзовый `#268A6D`, лавандовый `#7960C2`, коралловый `#C76650`, янтарный `#D28A2B`. Узлы имеют пастельную заливку и контрастную обводку.

|---|---|
| [edututor_overview.mmd](edututor_overview.mmd) | Основные компоненты и участники |
| [learning_journey.mmd](learning_journey.mmd) | Маршрут магистранта |
| [platform_architecture.mmd](platform_architecture.mmd) | STUDENT / MAS / TEACHER |
| [agent_orchestration.mmd](agent_orchestration.mmd) | Оркестрация и маршрутизация |
| [rag_pipeline.mmd](rag_pipeline.mmd) | Поток учебных данных и поиск |
| [course_structure.mmd](course_structure.mmd) | Дисциплина → тема → занятие → материалы |
| [moodle_context.mmd](moodle_context.mmd) | Контекст Moodle |
| [teacher_workflow.mmd](teacher_workflow.mmd) | Управление материалами и обратная связь |
| [responsibility_boundaries.mmd](responsibility_boundaries.mmd) | Границы ответственности |

Нет двоичных изображений схем и нет тестовых протоколов. Режим редактирования `.mmd`: любой текстовый редактор с подсветкой Mermaid или Mermaid Live Editor.
