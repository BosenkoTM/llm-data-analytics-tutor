# Архитектурные диаграммы Mermaid

В каталоге размещены редактируемые файлы `.mmd`, используемые во встроенных диаграммах Markdown. Диаграммы помогают понять учебные процессы, архитектуру сервисов и границы ответственности компонентов EduTutor.

| Файл | Содержание |
|---|---|
| [edututor_overview.mmd](edututor_overview.mmd) | Учебный контур, Tutor и база знаний |
| [learning_journey.mmd](learning_journey.mmd) | Маршрут обучающегося |
| [platform_architecture.mmd](platform_architecture.mmd) | Архитектура платформы |
| [agent_orchestration.mmd](agent_orchestration.mmd) | Управление специализированными агентами |
| [rag_pipeline.mmd](rag_pipeline.mmd) | Подготовка материалов и поиск |
| [course_structure.mmd](course_structure.mmd) | Структура учебного контента |
| [moodle_context.mmd](moodle_context.mmd) | Интеграция Moodle |
| [teacher_workflow.mmd](teacher_workflow.mmd) | Сценарий преподавателя |
| [responsibility_boundaries.mmd](responsibility_boundaries.mmd) | Разделение ответственности |

Все диаграммы задаются синтаксисом Mermaid с единым визуальным оформлением. Текст узлов разделён на короткие строки; сложные диаграммы используют вертикальную компоновку, чтобы повысить читаемость на GitHub и мобильных экранах. Исходники синхронизированы с блоками `mermaid` в документации.

Раздел [`tutor-loader-vkr`](../tutor-loader-vkr/README.md) содержит самостоятельные материалы квалификационного исследования и сохранён в исходном составе.
